Architecture logicielle embarquée

Le système repose sur une séparation claire des responsabilités entre le Raspberry Pi 5 (calculs lourds, LiDAR, ROS2, navigation) et l'Arduino Mega (pilotage moteurs, capteurs simples, actionneurs).

ROS2 Serial Pi ↔ Arduino Navigation stack LiDAR driver

Flux de communication embarqué

Raspberry Pi 5 (ROS2) ├─ Traitement LiDAR / navigation ├─ Logique de décision └─ Communication série └─ Arduino Mega ├─ Pilotage moteurs (L298N) ├─ Capteur ultrason └─ IMU (GY-521)
